# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Raymember is designed as a local-first persistent memory engine. All database data and web dashboard instances run locally on the developer's system.

If you discover a security issue or vulnerability:
1. Please report it privately to `security@raymember.ai`.
2. Do not open public issues for security vulnerabilities.
3. We will acknowledge receipt within 48 hours and work with you on a resolution.
